# کلاچ پینگ — وب‌سایت جدید (ClutchPing)

بازطراحی وب‌سایت [کلاچ پینگ](https://clutchping.com) با یک هویت بصری مستقل؛ وب‌سایتی چندصفحه‌ای، فارسی و راست‌به‌چپ که روی GitHub Pages منتشر می‌شود.

- **نسخهٔ آنلاین:** https://yaspieze.github.io/clutchping/
- **پایگاه کد:** https://github.com/yaspieze/clutchping

> این پروژه یک بازنویسی مستقل است. هیچ کد، استایل یا مارک‌آپی از سایت فعلی یا سایت‌های مرجع کپی نشده؛ فقط نام برند، فهرست سرورها، قیمت‌ها و متن‌های سیاست‌ها از اطلاعات عمومی همان سایت گرفته شده‌اند.

---

## فهرست صفحه‌ها

| مسیر | صفحه | توضیح |
| --- | --- | --- |
| `/` | خانه | هیرو با نمودار مسیر، آمار، مراحل اتصال، سرورهای ویژه، مقایسهٔ پلن‌ها، لیدربورد، حمایت، پرسش‌های کوتاه |
| `/servers/` | سرورها | فهرست کامل ۲۸ سرور با جست‌وجو و فیلتر (همه/جاوا/بدون اکانت/بدراک، همیشه/پایه/پلاس) + آدرس بدراک |
| `/store/` | اشتراک‌ها | دو پلن پایه و پلاس، چهار دورهٔ ۳۰/۹۰/۱۸۰/۳۶۵ روزه با محاسبهٔ زندهٔ تخفیف، جدول مقایسه، فهرست پوشش |
| `/order/` | ثبت سفارش | انتخاب پلن و دوره، نام ماینکرفت با پیش‌نمایش اسکین، شمارهٔ موبایل، اعتبارسنجی و خلاصهٔ قابل کپی |
| `/leaderboard/` | لیدربورد | جدول هفتگی، نشان‌ها، نوارهای سهم زمان بازی |
| `/donate/` | حمایت | پیشرفت هدف، سطوح حمایت، دیوار حامیان، فرم مبلغ دلخواه |
| `/faq/` | سؤال‌ها | ۱۴ پرسش دسته‌بندی‌شده با آکاردئون و لنگر مستقیم |
| `/blog/` | راهنما | فهرست مقالات فنی |
| `/blog/ping-lag/` | مقاله | «پینگ، پکت‌لاس و لگ: کدام‌یک تجربهٔ بازی را خراب می‌کند؟» |
| `/blog/hypixel-setup/` | مقاله | «اتصال به هایپیکسل بدون دردسر» |
| `/terms/` | قوانین | شرایط اشتراک با فهرست مطالب چسبان |
| `404.html` | خطا | صفحهٔ ۴۰۴ اختصاصی |

سایت به‌صورت MPA ساخته می‌شود: برای هر مسیر یک `index.html` واقعی تولید می‌شود، پس لینک‌دهی مستقیم و رفرش در GitHub Pages بدون تنظیم ریرایت کار می‌کند.

## پشتهٔ فناوری

- **React 19 + TypeScript** (strict) — بدون روتر؛ هر صفحه یک نقطهٔ ورود سبک است.
- **Vite 8** در حالت چندصفحه‌ای (چند ورودی HTML).
- **CSS دست‌نویس با توکن** (`src/styles/tokens.css`) — بدون فریم‌ورک UI و بدون وابستگی اضافه؛ کل CSS خروجی حدود ۴۷ کیلوبایت (۹.۵ کیلوبایت gzip) است.
- **بدون بک‌اند:** فرم‌ها کاملاً سمت کلاینت اعتبارسنجی می‌شوند و خروجی‌شان خلاصهٔ قابل کپی + لینک به فروشگاه رسمی است (هیچ پرداخت یا ارسال واقعی‌ای انجام نمی‌شود).

### ساختار پوشه‌ها

```
src/
  entries/        نقطهٔ ورود هر صفحه (mount)
  pages/          کامپوننت هر صفحه
  components/     Header, Footer, Topology, ui, Icons, LeaderTable
  data/           سرورها، پلن‌ها، سؤالات، قوانین، مقالات
  lib/            toast، هوک‌ها (reveal، copy، dismiss)
  styles/         tokens → base → ui → pages
public/           فونت، تصاویر سرورها، آیکون‌ها، sitemap، manifest
```

## فونت

فقط خانوادهٔ **YekanBakh** با وزن‌های ۳۰۰، ۴۰۰، ۶۰۰ و ۷۰۰ به‌صورت self-hosted (`public/assets/fonts/*.woff2`) و با `@font-face` بارگذاری می‌شود؛ `font-synthesis: none` تا هیچ وزن جعلی (faux bold) ساخته نشود. پوشش حروف فارسی و ارقام فارسی بررسی شده است.

## فارسی و RTL

- `<!doctype html>` با `lang="fa"` و `dir="rtl"` در همهٔ صفحه‌ها.
- چیدمان با ویژگی‌های منطقی (`margin-inline`, `padding-inline`, `inset-inline`) نوشته شده تا RTL بدون آینه‌سازی دستی درست بماند.
- ارقام فارسی با جداکنندهٔ هزارگان «٬» و واحد «تومان» داخل همان خط.
- تاریخ‌ها با تقویم و ارقام فارسی.

## ویژگی‌ها

- منوی دسکتاپ با مگا‌منو، حالت فعال، دسترسی با کیبورد (`Esc` می‌بندد) و منوی کشویی موبایل.
- نمودار مسیر (دستگاه → کلاچ پینگ → مقصد) به‌صورت SVG با بسته‌های متحرک.
- جست‌وجوی زنده و فیلتر چندتایی روی سرورها، با حالت «نتیجه‌ای نیست».
- محاسبهٔ زندهٔ قیمت و تخفیف دوره در صفحهٔ اشتراک‌ها و سفارش.
- پیش‌نمایش اسکین ماینکرفت از نام کاربری، همراه با اعتبارسنجی فرم‌ها و پیام‌های خطای فارسی.
- کپی آدرس سرور با بازخورد متنی و toast.
- انیمیشن‌های ورود بخش‌ها با `IntersectionObserver` و احترام کامل به `prefers-reduced-motion`.
- تصاویر WebP، فونت `woff2`، بدون کتابخانهٔ آیکون یا فونت بیرونی.
- SEO: عنوان و توضیح اختصاصی هر صفحه، `sitemap.xml`، `robots.txt`، Open Graph و manifest.

## اجرا

```bash
npm install
npm run dev        # سرور توسعه
npm run typecheck  # بررسی تایپ‌ها
npm run build      # خروجی در dist/
```

برای انتشار زیر مسیر پروژه (project pages):

```bash
BASE_PATH=/clutchping/ npm run build
```

## انتشار

پوشهٔ `.github/workflows/deploy.yml` در هر push به شاخهٔ `main` این کارها را انجام می‌دهد: نصب وابستگی‌ها، بررسی تایپ، ساخت با `BASE_PATH=/clutchping/`، و انتشار روی GitHub Pages. برای فعال‌سازی، در تنظیمات مخزن → Pages → Source گزینهٔ **GitHub Actions** انتخاب می‌شود.

## محدودیت‌ها

- فرم سفارش و فرم حمایت به سرور وصل نیستند؛ به‌جای نمایش موفقیت جعلی، خلاصهٔ سفارش را برای کپی می‌دهند و به فروشگاه رسمی ارجاع می‌دهند.
- لیدربورد و آمار حامیان از داده‌های عمومی سایت فعلی گرفته شده و به‌صورت دستی به‌روزرسانی می‌شوند.
- محتوای مقالات راهنما عمومی و آموزشی است و عدد یا ادعای اندازه‌گیری‌شده‌ای به برند نسبت نمی‌دهد.
- آدرس مستقیم سرورها فقط برای نسخهٔ بدراک (IP مشترک با پورت‌های متفاوت) نمایش داده می‌شود؛ مسیرهای جاوا با اشتراک باز می‌شوند، مطابق سیاست فعلی سرویس.

## اعتبار تصاویر

آواتار سرورها از سرویس‌های عمومی آیکون ماینکرفت (MC-Heads / Minotar) گرفته شده و در مخزن به‌صورت WebP ذخیره شده است. بقیهٔ گرافیک‌ها (نمودار مسیر، آیکون‌ها، تصویر Open Graph و آیکون اپلیکیشن) در همین پروژه ساخته شده‌اند.

## English (short)

Original multi-page frontend for ClutchPing: React 19 + TypeScript + Vite (MPA), hand-written token-based CSS, self-hosted YekanBakh, Persian/RTL only, deployed to GitHub Pages via Actions under `/clutchping/`. No backend — forms validate client-side and hand off a copyable summary instead of faking a submission. No code or styling copied from the previous site or the reference sites.
